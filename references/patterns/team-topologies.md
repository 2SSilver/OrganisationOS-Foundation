# Team Topologies

## Summary

Team Topologies (Skelton & Pais) names four team types — Stream-Aligned, Enabling, Complicated-Subsystem, Platform — and three interaction modes — Collaboration, X-as-a-Service, Facilitating. The framework focuses on team cognitive load and clean team-to-team interfaces.

## When to use

- Designing how domains in this harness interact: which act as services, which collaborate continuously, which enable
- Reviewing whether a domain has taken on too much cognitive load
- Naming interaction-mode mismatches that surface in cross-domain friction

## Canonical source

Matthew Skelton & Manuel Pais, "Team Topologies" — https://teamtopologies.com/

## Note on use in OrganisationOS

The harness's "interface" pattern (`foundation/interfaces/`) loosely maps to the X-as-a-Service interaction mode. Adopters using Team Topologies seriously may name each interface with the interaction mode it represents.
