# Flow Engineering

## Summary

Flow Engineering (Steve Pereira) is a five-map sequence for value-stream alignment: Outcome Mapping → Current-State Value Stream Mapping → Dependency Mapping → Future-State Value Stream Mapping → Flow Roadmapping. Designed for cross-functional groups to align on what to improve and in what order.

## When to use

- Annual planning rituals at the Leadership Forum
- Onboarding a new domain by mapping its value stream against the rest of the organisation
- Diagnosing where flow breaks down across domains

## Canonical source

Steve Pereira & Andrew Davis, "Flow Engineering" — https://flowengineering.com/

## Note on use in OrganisationOS

Several adopters use Flow Engineering's five-map as the Leadership Forum's annual planning artefact. The Forefront ITM example (in `examples/itm/`) adopts this pattern.
