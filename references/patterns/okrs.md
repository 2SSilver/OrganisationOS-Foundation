# OKRs

## Summary

OKRs (Objectives and Key Results) are outcome-oriented planning artefacts. An objective is a qualitative direction; key results are quantitative measures of progress toward it. Distinguish leading from lagging indicators; keep key results in the team's sphere of influence; treat OKRs as a focus tool, not a performance-review instrument.

## When to use

- Aligning a domain on a small number of outcomes per quarter or planning period
- Surfacing leading indicators of strategic progress
- Communicating priority to stakeholders without committing to specific outputs

## Canonical sources

- John Doerr, "Measure What Matters"
- Christina Wodtke, "Radical Focus" — <https://eleganthack.com/>
- Tim Herbig, "Outcome OKRs" — <https://herbig.co/>

## Note on use in OrganisationOS

Common failure modes: output-shaped key results (a count of features shipped) rather than outcome-shaped (a behaviour change); OKRs imported wholesale into individual performance reviews; quarterly OKR sets without a mid-quarter check-in. The `okr-advisor` skill in PAI's skill library is a useful coach.
